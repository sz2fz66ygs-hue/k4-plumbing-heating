# K4 Plumbing & Heating Website

Professional single-page website for K4 Plumbing & Heating — Honest plumbing. Fair prices. No surprises.

## Live Site
Once GitHub Pages is enabled, the site will be available at:
**https://sz2fz66ygs-hue.github.io/k4-plumbing-heating/**

## Enable GitHub Pages
1. Go to the repository Settings → Pages
2. Source: Deploy from a branch
3. Branch: main / (root)
4. Save

## Customise Before Launch
- Replace all instances of `44XXXXXXXXXX` with your real WhatsApp/phone number (UK format: 447XXXXXXXXX without + or spaces)
- Update the email address
- Adjust any prices in the quotation guide if needed
- Optionally add your logo image and update the header
- The form currently opens WhatsApp with a pre-filled message

Built as a clean, mobile-first, interactive site with sticky header, floating WhatsApp button, accordions, scroll animations, and strong focus on trust and transparent pricing.
